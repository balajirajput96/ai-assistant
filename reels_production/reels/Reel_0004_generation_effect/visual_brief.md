# Reel 0004 Visual Brief — Attempt Before Answer

## Production choice

The daily AI-image quota remains unavailable. Reel 0004 therefore uses an original, topic-specific **motion-graphics visual set** generated from source-controlled geometry. The scenes are text-free and leave lower-centre space for Hindi captions.

| Scene | Visual job | Conceptual treatment |
|---|---|---|
| 1 | Present a meaningful unanswered question | A glowing question orb hovers above a closed card, showing a deliberate attempt before reveal. |
| 2 | Show feedback, not uncorrected error | The tentative amber response routes into a teal verified-answer card and a calm correction pulse. |
| 3 | Show the three-step routine | Three connected nodes represent attempt, feedback, and recall without using text. |
| 4 | Reinforce the takeaway | A circular path reconnects the original question and a brighter answer signal, representing later retrieval. |

## Style

Use a midnight-indigo background, ultraviolet gradients, teal verification light, amber attempt light, and coral correction accents. Soft glow, rounded educational objects, and gentle camera movement during encoding create a distinct science-and-learning visual style.
